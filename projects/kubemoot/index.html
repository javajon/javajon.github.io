Kubemoot

An open-source Kubernetes operator for agentic AI

  • My role: Creator / Maintainer
  • Published: Open Source
Visit Site View on GitHub

What it is

Kubemoot is an open-source Kubernetes operator that makes AI agents first-class, reconciled citizens of your cluster. Agent policies, tool access, and reasoning rules are expressed as Custom Resources — the same Kubernetes primitives that already run your deployments, scaling, and networking.

Architecture Definition Language (ADL) rules compile down to Custom Resources that govern how agents reason: WHEN/THEN conditions replace verbose prompts, ASSERT enforces boundaries, and a kubectl apply changes agent behavior with no recompilation. GPU-aware scheduling, MCP tool servers as sidecars, and RAG pipelines all fit the same reconciliation model Kubernetes was already built for.

The dashboard

Kubemoot’s dashboard surfaces agents, their reconciled state, and the moot they’re part of as they run.

Why Kubernetes

CRDs, reconciliation loops, and schedulers were already the right primitives for agentic AI — Kubemoot just connects them. Instead of a bespoke orchestration framework bolted on top of your infrastructure, agents become workloads your cluster already knows how to run, observe, and govern.
